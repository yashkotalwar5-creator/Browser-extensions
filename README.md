# YouTube Auto Ad-Skipper 🎥⚡

A lightweight, minimal browser automation tool that automatically clicks the "Skip Ad" button on YouTube the millisecond it becomes active. 

---

## 🚀 Features
* **Auto-Clicking:** Scans the page every 500ms to click any variation of the "Skip Ad" button.
* **Fast-Forward:** Automatically speeds up and jumps to the final split-second of unskippable ads.
* **Privacy First:** Zero trackers, zero permissions required, and 100% open source.

---

## 🌐 Installation Instructions

### Option 1: Google Chrome (and Brave / Edge / Opera)
1. Open Google Chrome and navigate to `chrome://extensions/`.
2. In the top-right corner, toggle **Developer mode** to **ON**.
3. In the top-left corner, click **Load unpacked**.
4. Select the `chrome-extension` folder inside this repository.

### Option 2: Apple Safari (macOS)
1. Open the Mac App Store and download **Userscripts**.
2. Open Safari Settings -> Extensions, and ensure Userscripts is enabled.
3. Click the Userscripts toolbar icon, open the dashboard, and link it to the `safari-userscript` folder inside this repository.
